# Thunderbirds-Remake
A Unity project of the 1985 game Thunderbirds fan remake

## Getting Started
1. Install **Unity 6000.3.20f1** via Unity Hub (the exact version is in `ProjectSettings/ProjectVersion.txt`).
2. Install [Git LFS](https://git-lfs.com) and run `git lfs install` once — images, audio, and PDFs are stored with LFS.
3. Clone the repo, then in Unity Hub choose **Add → Add project from disk** and select the `Thunderbirds-Remake/` folder (the one containing `Assets/`).
4. The first open takes a while — Unity rebuilds the `Library/` cache locally.
